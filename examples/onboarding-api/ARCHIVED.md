# onboarding-api (archived copy)

Example service generated with the `python-service` template: 6 endpoints, 11 tests, OpenAPI, Dockerfiles, Kubernetes manifests and New Relic config. It lived in its own repository (`jh-platform-lab/onboarding-api`), now removed; this copy keeps the example available.

Run the tests: `pip install -r requirements-dev.txt && python -m pytest -q`. Sample requests: `curl-evidence.txt`. The `.github/` workflows were left out because they only run at a repository root.
