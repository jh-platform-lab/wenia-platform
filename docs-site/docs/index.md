# Plataforma de autoservicio Wenia

Un formulario en Backstage crea un microservicio completo: repositorio, entradas de catálogo
(Component y API), Dockerfile, CI/CD en GitHub Actions, Terraform y observabilidad con New Relic.

| Quiero... | Voy a... |
|---|---|
| Crear un servicio | **Create** → plantilla Python, Node.js, Go o Java |
| Crear infraestructura | **Create** → bucket S3 o cola SQS |
| Ver qué existe | **Catalog** y **Catalog Graph** |
| Entender una API | **APIs** |

Cada servicio nuevo trae su propia documentación en **Docs**.
